# GroupMate

Agile team project - GroupMate CW Repo

GroupMate is a landing page for a group-work app that helps students form teams, share tasks and stay on track together.

## Features

- Clean dark-blue theme
- Problem / solution overview
- 3-step onboarding guide
- Waitlist sign-up form
- Team section and FAQ accordion
- Prototype preview screenshots

## Built With

- HTML
- CSS

## Project Structure

```
GroupMate/
├── images/       # Images, screenshots and icons
├── index.html    # Main landing page
├── style.css     # Styles and theme
└── README.md
```

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/its-arshad90/GroupMate.git
   ```
2. Open `index.html` in your web browser.
